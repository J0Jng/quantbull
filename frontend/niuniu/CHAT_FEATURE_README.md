# 智能投资顾问聊天窗口功能说明

## 功能概述
为量化投资平台添加了一个智能悬浮聊天窗口，提供专业的投资顾问服务。该功能使用Vue 3 Composition API实现，集成了后端AI聊天接口。

## 功能特性

### 核心功能
- ✅ **悬浮式设计**: 固定在页面右下角的聊天图标，不影响主要内容浏览
- ✅ **展开/收起**: 点击图标展开聊天窗口，支持最小化
- ✅ **拖拽移动**: 可拖拽聊天窗口到任意位置
- ✅ **多轮对话**: 支持连续对话，保持上下文连贯
- ✅ **实时响应**: 显示消息发送时间和加载状态
- ✅ **消息区分**: 用户消息和AI回复使用不同颜色和位置
- ✅ **历史记录**: 自动保存对话历史（最大50条）
- ✅ **按键优化**: Enter发送，Shift+Enter换行

### API集成
- ✅ 使用 `/api/ai/api/ai/chat` 接口
- ✅ 支持自动模型路由（DeepSeek、Qwen、OpenAI）
- ✅ 自定义系统提示词（专业投资顾问角色）
- ✅ 错误处理和友好提示

### UI/UX设计
- ✅ 使用项目主色调橙色 (#ff7f00)
- ✅ 符合金融平台的专业性需求
- ✅ 响应式设计，支持移动端
- ✅ 无障碍访问支持
- ✅ 动画效果和过渡

## 组件配置

### ChatWidget.vue 属性
- `system-prompt`: 自定义系统提示词（可选）

### 状态管理 (chat.js)
```javascript
// 主要状态
isChatOpen: 聊天窗口是否打开
isChatMinimized: 是否最小化
chatHistory: 聊天记录数组
isLoading: 是否正在加载

// 主要方法
toggleChat(): 切换聊天窗口
addMessage(): 添加消息
clearChat(): 清空聊天记录
```

## API服务

### 主要方法
- `sendChat()`: 发送聊天消息
- `checkHealth()`: 检查API健康状态
- `generateStrategy()`: 生成投资策略代码
- `generateNewsAnalysis()`: 生成新闻解读

### 请求格式
```javascript
{
  message: "用户输入",
  system_prompt: "系统提示词",
  model: null, // 自动路由
  temperature: 0.7,
  max_tokens: 1000
}
```

## 使用示例

### 基本使用
1. 页面右下角点击聊天图标
2. 输入投资相关问题
3. 按Enter发送，等待AI回复

### 投资相关问题示例
- "帮我分析一下当前市场趋势"
- "推荐一些低风险的理财产品"
- "如何构建投资组合？"
- "解释一下技术分析的基本原理"

# 牛牛量化投资平台 - 数字人视频生成功能说明

## 功能概述

本功能为牛牛量化投资平台集成了AI数字人视频生成功能，用户可以通过右下角的AI对话框在文字聊天和数字人视频生成模式之间切换。

## 已实现功能

### 1. 双模式聊天界面
- **文字模式**：传统的文字聊天交互
- **视频模式**：AI生成专业口播的金融投资视频内容

### 2. 数字人视频生成
- 集成 `/api/ai/api/ai/digital-human/generate` API
- 支持生成专业金融投资内容的数字人口播视频
- 视频时长控制在10-120秒之间（默认40秒）

### 3. 金融合规性检查
- 自动验证生成内容是否符合金融监管要求
- 过滤违规承诺收益相关内容
- 确保投资风险的适当提示

### 4. UI/UX优化
- 与现有橙色主题（#ff7f00）保持一致
- 清晰的模式指示和状态提示
- 响应式设计，支持移动端

## 技术实现

### 核心文件
- `src/services/digitalHumanService.js` - 数字人视频生成服务
- `src/stores/chat.js` - 扩展状态管理支持模式切换
- `src/components/ChatWidget.vue` - 主聊天组件集成数字人功能

### API集成
```javascript
// 请求格式
{
  "text": "口播文本内容",
  "duration_limit": 40,
  "voice_style": "professional"
}

// 响应格式
{
  "video_url": "视频URL",
  "task_id": "任务ID",
  "estimated_duration": 40,
  "status": "completed"
}
```

## 如何使用

### 1. 基本使用
1. 点击右下角的聊天图标打开AI对话框
2. 在标题栏点击模式切换按钮（文字💬/视频??）
3. 输入投资相关问题
4. 点击发送或按Enter键

### 2. 视频模式功能
- 在视频模式下输入问题，AI会：
  - 分析问题并生成适合口播的专业金融内容
  - 进行合规性检查
  - 调用数字人API生成视频
  - 显示生成的视频和文字解读

### 3. 合规性保证
系统会过滤以下类型的内容：
- 保证收益、稳赚不赔等承诺
- 内幕消息、独家渠道等表述
- 具体个股推荐（避免合规风险）

主要颜色变量：
- 主色调：`#ff7f00` (橙色)

## 功能特点

### 优势
1. **专业内容**：专门针对金融投资场景优化的内容生成
2. **合规安全**：内置金融监管合规检查
3. **用户体验**：流畅的模式切换和无缝集成
4. **响应式设计**：适配不同屏幕尺寸

### 限制
1. 依赖后端数字人服务的可用性
2. 视频生成需要一定的处理时间
3. 内容长度限制为适合视频播放的格式

## 🔧 故障排查

### 问题 1：页面显示"暂无数据"
**可能原因：**
- data-service 服务未启动
- API_BASE_URL 配置错误

**解决方法：**
1. 检查 data-service 是否运行在 8000 端口
2. 检查前端 `.env` 文件中的 `VITE_API_BASE_URL`
3. 检查浏览器控制台是否有 CORS 或网络错误

### 问题 2：行业数据显示"尚未生成"
**可能原因：**
- 后台行业排名缓存未预热

**解决方法：**
1. 使用 Postman 或 curl 调用预热接口：
   ```bash
   curl "http://localhost:8000/api/fundamentals/industry/rank?auto_calculate=true"
   ```
2. 等待 10-15 分钟计算完成
3. 刷新页面

### 问题 3：K线图不显示
**可能原因：**
- 股票代码没有日线数据
- 日期范围内无交易日

**解决方法：**
1. 检查控制台错误信息
2. 尝试切换到其他股票
3. 确认该股票在选定日期范围内有交易

### 问题 4：表格列显示异常
**检查项：**
- [ ] 是否还有公式计算的字段（如 `stock.price * (1 - stock.pct_change / 100 * 0.5)`）
- [ ] 是否有带 `*` 的伪造数据标记
- [ ] 换手率、成交额是否显示 `--` 而非计算值

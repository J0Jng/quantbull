## 注意事项

1. **模拟数据**: 测试使用模拟数据，不依赖外部服务（data-service、Tushare）
2. **异步测试**: 使用 `pytest-asyncio` 处理异步函数测试
3. **测试隔离**: 每个测试都是独立的，不依赖其他测试的状态
4. **跳过测试**: `test_run_backtest_builtin` 在 API 测试中被跳过，因为需要真实数据服务
